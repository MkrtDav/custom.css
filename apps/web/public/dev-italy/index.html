Developer kits

One kit per Jira task. The task states the requirement; its kit holds the reference detail a developer or tester needs: ADM rules with sources, flows, message and return-code tables, and an acceptance checklist.

Where to look: the task for what must be built, the kit for how ADM defines the detail, ADM's protocol as the final source. If they differ, the task prevails over the kit and the protocol prevails over the task.
