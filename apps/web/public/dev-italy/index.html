Netbet ItalyADM remote gaming concession: developer kits

Developer kits

One kit per Jira task: the ADM rules with their sources, flows, and message and return-code tables. The task states the requirement. If a kit and its task differ, the task prevails; if the task and ADM's protocol differ, the protocol prevails.

ADM protocols

The five protocol kits are the main ones. Each has a rehearsal bench with fake data.
